# Video Bot 2.2 — онлайн-видео → Файлы iPhone без временного файла

## Как работает
1. Отправьте публичную ссылку на видеоролик в Telegram-бот.
2. Выберите качество (360p, 720p, 1080p или лучшее доступное).
3. Нажмите появившуюся кнопку «📥 Скачать … в Файлы».
4. Откройте ссылку в Safari. Бот снова анализирует видео, получает доступный MP4/HLS/DASH поток через yt-dlp и передаёт фрагментированный MP4, создаваемый FFmpeg, напрямую по HTTPS. Готовый файл не сохраняется на сервере или в Telegram.
5. В приложении «Файлы» → «Загрузки» найдите скачанное видео.

## Реальные ограничения
- Нет фиксированного ограничения размера файла в МБ в потоковом режиме. Но Railway ограничивает обычный HTTP-запрос примерно 15 минутами, наше приложение завершает его через 13 минут, а продолжение загрузки через HTTP Range пока не поддерживается.
- Safari, сеть пользователя, скорость сайта, доступные кодеки и ограничения HTTP-прокси влияют на возможность скачать большой файл.
- HLS/DASH поддерживаются, когда FFmpeg может прочитать поток и собрать MP4; DRM, платные закрытые видеопотоки, прямые трансляции, принудительная авторизация и проверка против ботов не обходятся.
- Ссылки одноразовые; после выбора качества кнопка действительна 10 минут до начала скачивания.
- Одновременная передача: один видеопоток; количество ссылок ограничено для защиты сервера от злоупотреблений.
- Маленькие файлы по-прежнему можно отправлять в Telegram до 49 МБ в отдельном режиме.

## Важно для эксплуатации
Для публичного коммерческого бота нужен контроль исходящих сетевых соединений (egress firewall). Код проверяет исходные DNS/IP, но это неполная защита от SSRF через редиректы или сегменты HLS. Не публикуйте токены и приватные cookie в GitHub. Сохраняйте видео только при наличии права на это.

## Railway
- Используется существующий токен TELEGRAM_BOT_TOKEN.
- Публичный домен Railway должен вести на PORT (обычно 8080); проверка GET /health.
- Ссылка на скачивание использует RAILWAY_PUBLIC_DOMAIN либо PUBLIC_BASE_URL.
- Dockerfile устанавливает Python, yt-dlp, Node.js и FFmpeg.
- HTTP GET /stream/{token} выдаёт файл MP4 частями с Content-Disposition: attachment.
- HTTP Range и возобновление прерванной загрузки не поддерживаются.
- Резервная копия предыдущего кода: backup-before-streaming-2026-11-07.
