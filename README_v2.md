# Video Bot 2.1 — потоки HLS/DASH → Файлы iPhone

Бот не требует наличия кнопки «Скачать» на исходном сайте. Он извлекает общедоступные незашифрованные видео с помощью yt-dlp и при необходимости соединяет дорожки через FFmpeg.

## Использование
1. Отправьте ссылку на публичное видео.
2. Сначала выберите качество: 360p, 720p, 1080p или «Авто».
3. Бот подготовит файл MP4 из доступного MP4, HLS или DASH.
4. Нажмите «Скачать в Файлы». Откроется временная HTTPS-ссылка Safari. В Telegram файл не загружается.
5. Временная серверная копия удаляется через 20 минут.

## Ограничения
- По умолчанию 250 МБ на видео (MAX_DOWNLOAD_MB), максимум 600 МБ на нынешнем сервере.
- 1 одновременная задача, 3 попытки на человека в час, 40 в сутки на весь бот.
- Для полноценных видео по 5 ГБ потребуется иная архитектура с потоковой передачей или более крупным диском/временным облачным хранилищем.
- DRM, авторизацию, платный/закрытый доступ и блокировки видеосервисов не обходим.
- Видео с кодеком, неподходящим iOS, может сохраниться в «Файлы», но не воспроизводиться в «Фото».
- Перед публичным коммерческим использованием нужны egress-контроль (SSRF), мониторинг расходов и проверка прав на контент.

## Railway
- Существующий TELEGRAM_BOT_TOKEN сохраняется.
- Публичный HTTPS-домен должен вести на порт PORT (по умолчанию 8080).
- Сервер читает RAILWAY_PUBLIC_DOMAIN; для ручной настройки есть PUBLIC_BASE_URL.
- Доступ к готовому файлу только по случайному временно действующему URL.
- GET /health для проверки и GET /f/{token} для скачивания с поддержкой Range.
