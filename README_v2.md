# Video Bot 2.0 — тестовая ветка

Ветка `v2-direct-download-prototype` предназначена для проверки прямых загрузок на iPhone без хранения в Telegram. **Основная ветка `main` и работающий бот не меняются.**

Функции:
- Поиск готовых MP4/MOV со звуком из публичных URL с помощью yt-dlp.
- Кнопки скачивания в Safari/«Файлы» без передачи через наш сервер.
- Ограниченная отправка небольших файлов в Telegram до 49 МиБ как запасной вариант.
- Для HLS/DASH, раздельных потоков, DRM и закрытых источников прямая загрузка не гарантируется.

**Тестируйте отдельно:** используйте другого Telegram-бота и его собственный `TELEGRAM_BOT_TOKEN`. Один токен нельзя использовать одновременно в двух polling-процессах. Не размещайте токены в GitHub.

Кнопка с прямым URL не гарантирует сохранение: CDN иногда привязывает ссылку к IP, Referer, сеансу и сроку действия. Пользователь может выбрать «Открыть в Safari» и сохранить файл в «Файлы».

Ограничения и безопасность: тестовая версия не является универсальным downloader'ом и не обходит DRM. Для публичного большого трафика нужен отдельный аудит SSRF, лимитов, злоупотреблений и авторских прав.

Для запуска:
```
python -m pip install -r requirements.txt
python -m pytest -q tests/
TELEGRAM_BOT_TOKEN=... python bot.py
```
